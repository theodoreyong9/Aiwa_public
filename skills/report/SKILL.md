# Reports

An account of what was done and where things stand, for her or for someone she names.

- Start from the facts: the commits, the releases, the status file, the hub's history. Not from memory.
- Three parts, short: what is done (with the release of each thing), what is in progress (and how long is left), what is blocked or hers
  to decide.
- A spoken report (she asks her agent aloud) is five sentences at most: write it as `Hub/history/<project>.md` already tells it.
- A written report is a document (the docs skill), published with the tag `docs-report-…`.
